Rule-based AI Time Prediction, a small interactive Python program printing the current time in a city you name, computed from UTC with a fixed per-city offset, no machine learning model anywhere in it. ai_time.py's rule table is the whole mechanism.

| Station one: Run it

python3 ai_time.py

Python 3, standard library only. Type a supported city at the Enter city: prompt, or exit to quit. Closing the input also ends the program cleanly.

| Station two: The eight stations of the clock

CityOffset from UTCTime figure style

Names match without regard to case or surrounding spaces, so tokyo and a padded Tokyo both work, and exit quits the same forgiving way. Any other city prints that city is not added, in the form <city> is not added, then shows the UTC time labelled GMT. The current program uses the CITY_OFFSETS table and UTC arithmetic.

| Station three: Honest limits

Dive log note: offsets are fixed constants; they do not adjust for daylight saving, so a listed offset can differ from civil time when a city crosses a saving switch.
Dive log note: output is time of day only, hour, minute, second, zero padded, with no date shown even when an offset crosses midnight.

Times wrap correctly across midnight in both directions and the Kolkata half hour carries into the hour past 59 minutes. File list: ai_time.py, with time_for_city(city, now_utc) separated from the prompt loop for testing, test_ai_time.py run with python3 -m unittest, logo.png and banner.png, LICENSE under GPL-3.0.
